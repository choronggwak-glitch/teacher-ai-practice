3. 잘 정리된 요청문이 아니어도 괜찮아요

원하는 단추 이름이나 화면 모양을 몰라도 시작할 수 있습니다. 어느 수업에서 누가 쓸지부터 편하게 이야기해 주세요.

편하게 시작하는 문장

수업 시간에 발표할 학생을 고를 때 같은 학생이 자꾸 나와. 번호를 넣고 누르면 아직 발표하지 않은 학생을 골라 주는 화면이 있었으면 좋겠어. 나는 프로그램을 잘 모르니까 네가 쉬운 모양으로 만들어 줘.

Sites로 수업용 웹앱을 만들어 줘. 우선 검토할 수 있는 버전을 준비하고, 외부 공개나 공유 범위 변경 전에는 내 승인을 받아.
실제 학생 정보는 쓰지 말고 번호 또는 가상 자료로 만들어. 기존 파일을 지우지 마.

말하다가 생각이 바뀌면 덧붙이면 됩니다. 마이크가 없는 화면에서는 이 내용을 글로 입력합니다.

4. 첫 웹앱을 만들어 봐요

① 사용할 앱에서 새 대화를 열어요

코덱스에서 새 채팅을 엽니다. 「Work」라는 메뉴를 찾을 필요는 없습니다. 현재 제공되는 모델과 사용 가능한 권한으로 시작합니다. 학교에서 관리하는 설정은 바꾸지 않습니다.

② 만들기 도구 또는 작업 폴더를 골라요

입력창에 @Sites를 입력해 목록에 보이면 선택합니다. Sites는 사이트를 만드는 도구입니다. 목록이 보이지 않아도 “수업용 웹사이트를 만들어 줘”라고 요청할 수 있습니다. 도구를 쓸 수 없다는 안내가 나오면 강사에게 확인합니다.

③ 마이크가 보이면 말하고, 없으면 글로 보내요

입력창에 마이크 단추가 있으면 눌러 설명합니다. 음성 입력을 처음 쓰면 마이크 사용 권한을 확인합니다. 단추가 없거나 소리가 들어가지 않으면 아래 「문장 복사」를 이용하거나 직접 입력해도 같은 실습을 할 수 있습니다. 이 안내서는 특정 음성 기능의 설치를 요구하지 않습니다.

④ 만들고 싶은 화면을 이야기해요

처음에는 아래 발표자 뽑기를 그대로 사용해 보세요. 한 가지 기능부터 시작합니다.

첫 실습 · 발표자 뽑기

초등학교 5학년 교실에서 쓸 발표자 뽑기를 만들어 줘. 학생 이름 대신 1번부터 24번을 사용해. 「한 명 뽑기」, 「이번 시간 제외할 번호」, 「처음부터 다시」가 있으면 좋겠어. 이미 뽑은 번호는 다시 나오지 않게 해. 교실 뒤에서도 보이도록 숫자와 단추를 크게 해 줘.

실제 학생 정보는 쓰지 말고 번호 또는 가상 자료로 만들어. 기존 파일을 지우지 마.

⑤ 만들어진 화면을 직접 눌러 봐요

미리보기 또는 안내받은 파일을 열고 세 번 이상 눌러 봅니다. 설명만 나왔다면 “설명에 그치지 말고 실제로 열어서 쓸 수 있는 화면으로 만들어 줘”라고 보냅니다.

  • 뽑은 번호가 다시 나오지 않나요?
  • 제외한 번호가 나오지 않나요?
  • 다 뽑았거나 모두 제외했을 때 안내가 있나요?
  • 글씨가 교실 뒤에서도 읽을 만큼 큰가요?

⑥ 아쉬운 점을 한 가지씩 고쳐요

첫 수정 요청

지금 작동하는 기능은 유지해 줘. 뽑힌 번호를 더 크게 보여 주고, 학생이 볼 안내 문장을 한 줄로 줄여 줘. 수정한 뒤 앞서 확인한 기능이 여전히 작동하는지도 점검해 줘.

가상 학교 행사 준비 도구를 만들어 줘. 할 일, 가상 담당 역할, 기한, 완료 여부를 보고 찾을 수 있게 해 줘. 실제 이름과 연락처는 쓰지 마. 사용자가 새로 열었을 때 내용이 유지되는지 먼저 정하고 알려 줘. 저장 기능이 없으면 저장된 것처럼 보이지 않게 해. 처음 쓰는 교사 입장에서 눌러 보고 불편한 부분 한 가지를 고쳐 줘.

Sites로 수업용 웹앱을 만들어 줘. 우선 검토할 수 있는 버전을 준비하고, 외부 공개나 공유 범위 변경 전에는 내 승인을 받아.
실제 학생 정보는 쓰지 말고 번호 또는 가상 자료로 만들어. 기존 파일을 지우지 마.

자료를 그대로 나열하는 것에서 한 걸음 더 나아가, 사용하는 교사가 무엇을 먼저 알고 싶은지 생각하게 하는 활동입니다.

18. 선택 · 내 도구를 링크로 나눠요

화면이 완성되면 먼저 내 컴퓨터나 미리보기에서 확인합니다. 다른 사람이 여는 인터넷 주소를 만드는 일은 선택 활동입니다. 공개 전에 화면과 들어 있는 자료를 교사가 검토합니다.

코덱스에서 Sites로 만든 경우

공유 범위를 바꾸기 전에 “누가 볼 수 있는 상태인지”를 확인합니다. 나만 볼 수 있는 주소를 보낸다고 다른 사람이 자동으로 볼 수 있는 것은 아닙니다. 공개할 준비가 되면 아래 문장을 사용합니다.

공유 링크 준비 요청

완성한 웹앱을 다른 교사와 링크로 나눌 준비를 해 줘. 실제 학생 정보가 없는지 확인해. 공개할 내용, 사용할 계정과 서비스, 누가 볼 수 있는지, 비용을 먼저 알려 줘. 내가 승인하기 전에는 공개하거나 공유 범위를 바꾸지 마. 공개 수단이나 권한이 없으면 정확히 알려 줘.
  1. 공개할 화면과 비용을 확인하고, 원하는 범위를 정합니다.
  2. 승인 뒤 실제 공개 주소가 나오면 다른 교사의 기기에서도 열어 봅니다.
  3. 강사가 안내한 연수 공유 공간에 제목·주소·배운 점을 올립니다. 공유 공간이 없으면 짝에게 화면만 보여 줘도 됩니다.

공유 글 예시: [첫 웹앱] 우리 반 발표자 뽑기 / 만든 기능: 중복 방지 / 내가 고친 점: 글씨 크게 보기. 계정 주소나 학생 정보가 보이는 화면은 가리고 올립니다.
