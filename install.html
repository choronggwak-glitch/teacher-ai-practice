컴퓨터에 이미 앱이 있으면 다시 설치하지 않아도 됩니다. 웹브라우저에서 채팅하는 화면과 컴퓨터에 설치한 앱을 구별해 주세요. 사용할 수 있는 계정이 준비되어 있는지 강의 전에 확인합니다. 새 결제가 필요하면 먼저 강사와 의논합니다.

ChatGPT Work와 코덱스를 사용할 분

공식 ChatGPT 데스크톱 앱을 설치합니다. 3단계 시작 실습은 ChatGPT의 Work · Sites, 4단계 업무 실습은 Codex를 사용합니다. 웹에서 Work를 사용하는 분도 같은 계정의 기능 제공 여부를 확인합니다.

공식 앱 설치 페이지 열기
  1. 공식 페이지에서 Windows 컴퓨터는 「Download for Windows」(윈도용 받기)를 누릅니다. Mac은 해당 운영체제의 다운로드를 고릅니다.
  2. 받은 설치 파일을 열어 화면의 설치 안내를 따릅니다. 설치를 학교에서 제한한 기기라면 담당자에게 확인합니다.
  3. 앱을 열고 본인 계정으로 로그인합니다. 비밀번호나 인증번호는 이 안내서나 AI 대화에 적지 않습니다.
  4. 3단계 시작 실습: 제품 선택에서 「ChatGPT」를 고르고 입력창 위 「Chat / Work」 전환에서 「Work」를 선택합니다. 「@Sites」가 사용 가능한지 확인합니다. 4단계 업무 실습: 「Codex」를 고르고 「New chat」(새 채팅)을 엽니다.
  5. 문서 안에 「교사실습」 새 폴더를 만들고, 로컬 프로젝트나 작업 폴더로 연결합니다. 실제 학생 자료가 들어 있는 폴더는 고르지 않습니다.
시작 실습 준비: ChatGPT → Work → @Sites가 선택되는지 확인합니다. 아래 파일 만들기 확인 문장은 코덱스와 클로드 코드의 로컬 작업 준비를 확인할 때 사용합니다.

클로드 코드로 할 분

Claude 데스크톱 앱을 설치하고 「Code」 화면을 사용합니다. 공식 안내에 따르면 이 화면을 쓰기 위해 별도로 명령어용 프로그램을 설치할 필요는 없습니다.

클로드 공식 설치 안내 열기
  1. 공식 안내에서 Windows는 「Download for Windows」, Mac은 「Download for macOS」를 고릅니다.
  2. 받은 파일을 실행하고 설치 안내를 따릅니다. 앱을 연 뒤 본인 계정으로 로그인합니다.
  3. 앱 왼쪽의 「Code」(코드 작업)를 엽니다. 이 화면을 사용할 수 있는 계정이어야 합니다. 보이지 않거나 이용 안내가 나오면 강사에게 먼저 알려 주세요.
  4. 환경 선택에서 「Local」(내 컴퓨터)을 고르고, 문서 안에 만든 「교사실습」 폴더를 선택합니다.
  5. 파일 수정을 묻는 화면이 나오면 대상이 실습 폴더인지 확인합니다. 제공되는 경우 「Accept edits」(파일 수정 허용)를 선택할 수 있고, 「Manual」(직접 승인)로도 진행할 수 있습니다.
확인할 모습: Code 화면에서 Local 환경과 선택한 실습 폴더가 보입니다. 일반 채팅 화면에서만 머물러 있지 않은지 확인해 주세요.

설치가 끝났는지 확인해요

코덱스 또는 클로드 코드의 실습 폴더 대화에 아래 문장을 보내세요. Work · Sites 준비는 위의 선택 화면에서 따로 확인합니다.

설치 확인 문장

실습 준비가 되었는지 확인해 줘. 아직 웹사이트는 열지 마.
1. 지금 내가 사용 중인 앱과 작업 환경을 알려 줘.
2. 현재 작업 폴더가 새로 만든 교사실습 폴더인지 확인해 줘.
3. 원래 자료를 바꾸지 말고, 이 폴더에 준비확인.txt를 만들어 "설치 확인 완료"라고 적어 줘.
4. 파일을 만들 수 없다면 없는 권한이나 기능을 정확히 알려 줘. 다른 설정을 몰래 바꾸지 마.
끝나면 내가 확인할 파일 위치와 다음 단계인 Aside 연결 준비를 쉬운 말로 알려 줘.

세 가지를 확인하면 2단계로 갑니다. 체크 표시는 새로 열면 초기화됩니다.
