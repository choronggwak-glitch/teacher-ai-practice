그림이 있는 Aside 원본 안내 열기

먼저 이 순서로 준비해요

여기서는 코덱스·클로드 코드의 Aside 연결을 준비합니다. 3단계 시작 실습은 별도로 ChatGPT → Work → @Sites에서 시작합니다. Work와 Sites의 사용 가능 여부는 ChatGPT 계정에서도 확인해 주세요.

  1. 1단계에서 설치한 앱을 엽니다. 코덱스는 Codex, 클로드는 Code → Local에서 실습 폴더 대화를 사용합니다.
  2. Aside 브라우저를 설치하고 로그인합니다. 이미 설치하고 로그인했다면 그대로 둡니다. 아래 공식 받기 페이지를 사용하세요.
  3. 브라우저 데이터 가져오기나 비밀번호 관리자 설정을 묻는 화면에서는 선택 사항을 건너뛰어도 됩니다. 원본 안내에서는 「Skip」(건너뛰기)을 사용합니다.
  4. Aside를 켜 둡니다. 별도의 AI 제공자 계정 연결부터 할 필요는 없습니다. 이번에는 코덱스나 클로드 코드가 Aside를 직접 읽고 클릭하는 방식입니다.
  5. 아래에서 사용할 앱의 연결 문장 하나를 복사해 보냅니다. 실행 승인을 물으면 어떤 작업인지 읽고 허용 여부를 판단합니다.

사용할 앱확인할 곳할 일
코덱스입력창 아래 권한 선택파일 접근과 실행 요청을 확인합니다. 제공되는 승인 방식으로 진행하고, 전체 접근은 사용자가 이해하고 선택할 때만 사용합니다.
클로드 코드Code 화면의 권한 선택실습 폴더의 수정·실행 요청인지 읽어 봅니다. Accept edits나 Manual 등 제공되는 방식으로 진행할 수 있습니다.
학교 관리 기기기관의 관리 안내설정이 잠겨 있으면 강사나 담당자에게 확인합니다. 제한을 우회하지 않습니다.

원본의 「전체 액세스」 설정과 현재 앱의 권한 이름은 다를 수 있습니다. 오류 원문을 보지 않고 모든 실패를 로그인 또는 권한 문제라고 단정하지 않습니다. OpenAI 공식 권한 설명

코덱스용 연결 문장

코덱스의 실습 폴더 대화에 아래 문장 전체를 복사해서 보냅니다. 설치, 스킬 연결, 작업 규칙 저장을 AI에게 맡깁니다.

코덱스 연결 준비

나는 교사이고 컴퓨터 설정에 익숙하지 않아. 코덱스가 Aside를 직접 움직일 수 있도록 연결 준비를 해 줘. Aside 브라우저는 내가 설치하고 로그인해 둘게. 설치에 필요한 공식 안내 확인 외에는 아직 웹사이트를 열거나 실습을 시작하지 마.

1. Aside CLI가 이미 있는지 확인해. 없으면 https://docs.aside.com/help/developers의 현재 공식 설치 안내를 확인해 설치해. 설치·업데이트 파일은 releases.aside.com 또는 docs.aside.com에서만 받아. Windows에서는 설치 파일의 서명, 게시자와 시간 서명을 확인하는 공식 절차를 지켜. 서명 확인을 생략하거나 보안 설정을 끄지 마. 관리자 승인이나 사람의 조작이 꼭 필요하면 내가 할 일 한 가지만 알려 줘.
2. aside --update와 aside guide를 차례로 실행해 실제 안내를 읽어. 명령을 찾지 못하면 공식 설치 위치와 새 앱 실행이 필요한지부터 확인해.
3. aside skills install --target codex로 이 앱용 aside-browser 스킬을 설치해. 이미 있으면 중복 설치하지 말고 실제 SKILL.md 경로와 이 앱이 읽을 수 있는지 확인해.
4. Codex가 실제로 읽는 사용자 지침(AGENTS.md)의 실제 위치를 먼저 확인해. 기존 파일은 백업하고 원래 내용은 유지해. 아래 규칙이 없을 때만 덧붙여. 다른 지침과 충돌하면 무엇이 충돌하는지 먼저 알려 줘.
   웹사이트를 열고 읽고 입력하는 작업은 aside-browser 스킬을 읽고 Aside로 한다. 사용 전에 aside --update와 aside guide를 읽는다. aside repl로 직접 읽고 클릭하며, aside exec 등 Aside 안의 AI에게 일을 넘기는 명령은 쓰지 않는다. 사용자의 마우스·키보드와 보고 있는 창·탭을 건드리지 않는다. Aside가 실패하면 오류 원문과 필요한 사람의 일을 알리고 다른 브라우저로 바꾸지 않는다. Aside CLI 설치·업데이트는 releases.aside.com과 docs.aside.com의 공식 안내만 따른다.
5. 권한·승인 요청이 나오면 어떤 작업에 필요한지 설명해. 앱의 제한, 학교 관리자 정책, 명시적인 승인을 우회하지 마. 전체 권한이나 보안 해제를 몰래 설정하지 마.
6. Aside 오류를 로그인 문제라고 단정하지 마. 재설치·로그아웃·유료 가입·별도 AI 제공자 연결부터 요구하지 말고 오류 원문을 확인해.
7. 끝나면 세 가지만 알려 줘. ① CLI 준비 상태 ② 스킬·규칙 저장 위치 ③ 앱을 완전히 껐다 켜야 하는지. 실제로 하지 못한 일은 완료했다고 말하지 마.

유료 결제, 공개, 제출, 발송, 삭제는 하지 마. 내 마우스와 키보드, 보고 있는 창과 탭도 건드리지 마.

안내받았으면 앱을 다시 열어요

AI가 앱을 완전히 껐다 켜라고 하면 진행 내용을 저장한 뒤 사용자가 직접 다시 엽니다. Aside는 켜 둡니다. 새로 설치한 도구와 스킬이 앱에 보이도록 하는 과정입니다. 작업 중인 다른 문서나 프로그램을 먼저 저장해 주세요.

다시 연 앱에서 같은 실습 폴더를 선택하고 새 대화를 엽니다. 아래 연결 확인 문장을 보냅니다.

Aside 연결 확인

Aside 연결을 점검해 줘.
1. aside-browser 스킬과 현재 aside guide, aside guide repl을 읽어.
2. aside repl로 https://www.naver.com 첫 화면을 직접 읽고 페이지 제목만 알려 줘. Aside 안의 AI에게 맡기는 명령은 쓰지 마.
3. 내 마우스·키보드·보고 있는 창과 기존 탭은 건드리지 마. 웹사이트에 로그인하거나 입력·전송하지 마.
4. 실패하면 오류 원문과 내가 할 일 한 가지만 알려 줘. 다른 브라우저로 바꾸지 마.
실제로 읽어 확인했을 때만 연결 성공이라고 말해 줘.
연결 성공 기준
AI가 Aside로 실제 페이지를 읽고 「NAVER」 같은 페이지 제목을 알려 줍니다. 오류가 나오면 원문을 강사에게 보여 주세요. 다른 브라우저로 바꾸지 않습니다.

긴 실습을 위한 전원 확인

노트북은 전원을 연결하고 덮개를 열어 둡니다. 코덱스 앱 설정에 「실행 중 절전 모드 방지」가 보이면 강사의 안내에 따라 확인합니다. 다른 앱이나 버전은 같은 스위치가 없을 수 있습니다.

전원 설정 확인

실습 중 컴퓨터가 잠들지 않도록 현재 설정을 확인해 줘. 아직 설정을 바꾸지는 마.
앱에 작업 중 절전 방지 기능이 있는지와 현재 상태, 전원 연결 중 자동 절전 여부를 알려 줘. 학교 관리 설정이나 정책은 바꾸지 마.
필요한 변경이 있으면 공식 설정 화면의 위치와 내가 눌러야 할 글자를 쉬운 말로 알려 줘. 노트북 덮개 동작, 종료, 배터리 보호 동작은 바꾸지 마.
컴퓨터나 앱이 꺼진 뒤에도 작업이 계속된다고 말하지 마.

컴퓨터와 앱이 꺼지거나, 사용 한도·승인 요청 때문에 멈추면 작업이 자동으로 계속되는 것은 아닙니다. 이 안내에서는 정기 확인 예약을 만들지 않습니다.

잘 안될 때

이런 상황이면이렇게 해요
aside 명령을 찾지 못해요설치한 AI 앱을 완전히 다시 연 뒤 연결 준비 문장을 다시 보냅니다. 계속 안 되면 오류 원문을 강사에게 보여 주세요.
로그인되어 있는데 연결이 안 돼요오류 원문과 실행 권한, 선택한 계정·환경을 AI가 확인하게 합니다. 재설치나 로그아웃부터 반복하지 않습니다.
스킬을 못 찾는다고 해요내가 쓰는 앱용으로 설치했는지 확인합니다. 코덱스와 클로드 코드의 설치 대상이 다릅니다.
승인 요청이 떠요요청 내용을 읽고 실습에 필요한 작업인지 판단합니다. 모르는 요청은 강사에게 보여 주세요.
사이트나 화면이 그대로예요제목을 실제로 읽었는지 물어봅니다. 확인하지 않은 것을 성공으로 처리하지 않습니다.
